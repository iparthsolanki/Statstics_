# Inferential Statistics 

## Overview
This project is a Python-based data analysis notebook focused on Inferential Statistics and statistical techniques.

The notebook demonstrates important statistical concepts such as hypothesis testing, confidence intervals, p-values, covariance, correlation, and various statistical tests using a real-world health dataset.

The project combines theoretical explanations with practical implementation using Python libraries 

---

## Objective
The main objectives of this project are:

- Understand fundamental concepts of inferential statistics
- Perform statistical analysis on real-world data
- Apply hypothesis testing techniques
- Analyze relationships between variables
- statistical insights using graphs and charts
